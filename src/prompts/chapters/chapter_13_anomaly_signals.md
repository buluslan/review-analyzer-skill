## 十三、异常信号卡

### 分析目标

将预计算的异常检测数据渲染为独立决策卡，帮助决策者一眼定位"最该关注的异常"。本章节只做严重度分级聚合 + 决策建议，不重复展开分析——详细的时间趋势分析见第九章，评分文本情感背离分析见第十章。

### 输入数据

以下异常信号已由确定性规则预计算完成（非 AI 主观判断），你只需将其渲染为结构化决策卡：

{{ANOMALY_SIGNALS}}

### 渲染格式

#### 情况 A：存在异常信号

为每条信号输出一张决策卡，格式如下：

```
### ⚠️ [信号类型名称]

| 字段 | 内容 |
|------|------|
| **严重度** | 🔴 高 / 🟠 中 / 🟡 低 |
| **命中** | N 条（占比 XX.X%） |
| **来源标签** | [涉及的标签维度] |

**代表原话**：
> "[用户评论原话1]"
> "[用户评论原话2]"

**建议动作**：[按信号类型预设的动作建议]
```

卡片的排序规则：按严重度降序（高→中→低），同严重度按命中条数降序。

每张卡的"建议动作"应结合数据支撑给出具体、可执行的指令（2-3 句话），而非泛泛而谈。

#### 情况 B：无异常信号

如果输入数据为"本次未检测到异常信号"，则输出：

```
### ✅ 当前数据健康

本次分析未触发任何异常信号阈值，表明：

- 无大规模隐性流失迹象
- 无质量/售后问题集中爆发
- 无近期口碑恶化趋势
- 无复购流失预警

建议保持常规监控频率，关注下一周期的信号变化。
```

### 写作规范

1. **严重度徽章**：🔴=高（紧急干预）、🟠=中（重点关注）、🟡=低（持续监控）
2. **数据诚实**：严格使用预计算数据的占比和条数，不要自行估算或修改
3. **去重声明**：在章节末尾注明"详细时间趋势分析见第九章，评分文本情感背离详情见第十章"
4. **零编造**：如果某条信号的代表原话为空，标注"（无典型原话）"，不要编造
5. **动作导向**：每条建议动作必须包含动词（如"排查""升级""增设"），指向具体业务环节
6. 篇幅按信号数量自适应：无信号时 100 字内，有信号时每卡 80-120 字
